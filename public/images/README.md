# Imágenes referenciales

Coloca aquí las fotografías con estos nombres (jpg, webp o png). Cada una reemplaza automáticamente a la ilustración de respaldo:

| Archivo | Dónde aparece | Formato sugerido |
|---|---|---|
| `hero.jpg` | Inicio, primera pantalla | vertical 4:5, mín. 1200 px de ancho |
| `estrategia.jpg` | Inicio, sección "Tu estrategia" | 4:3 |
| `credito.jpg` | Bloque de crédito hipotecario (inicio y asesoría) | 16:9 |
| `nosotros.jpg` | Página Nosotros | 16:10 |
| `blog-primeros-pasos.jpg`, `blog-financiamiento.jpg`, `blog-rentabilidad.jpg`, `blog-riesgos.jpg`, `blog-estrategia.jpg` | Tarjetas del blog, por categoría | 16:9 |

Usa solo fotos propias o con licencia de uso comercial. Los textos alternativos están en `src/data/images.ts`.
